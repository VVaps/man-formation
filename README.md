# man-formation

## Description

Ce projet est un support développé pour les formations en cybersécurité. Il vise à sensibiliser les utilisateurs aux risques de phishing en récupérant et en analysant les informations de pages web via un script Python.

## Fonctionnalités

* Récupération d'informations depuis une page web à l'aide d'un script Python.
* Prévention et sensibilisation au phishing.
* Interface web développée avec le framework Next.js.

## Installation

### Prérequis

* Node.js >= 14
* npm >= 6
* Python 3.x

### Installation des dépendances

```bash
# Installer les dépendances pour Next.js
npm install

# Assurez-vous que Python est installé et accessible via la ligne de commande
```

## Utilisation

### Démarrer l'application Next.js

```bash
npm run dev
```

### Utiliser le script Python

```bash
python script.py
```

*(Remplacez `script.py` par le nom exact du script de récupération d'informations)*
